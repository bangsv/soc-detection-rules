# legacy-v1

Архив предыдущей версии интерфейса SOC Atlas (до переработки дизайн-системы).

Эти файлы **больше не подключены** ни к `index.html`, ни к `about.html`:

| Файл | Прежняя роль |
| :--- | :--- |
| `style.css` | базовая тема и раскладка первой версии |
| `enhancements.css` | стили страницы автора |
| `final-tweaks.css` | точечные правки карточек и материалов |
| `last.css` | поздние правки (уведомления, оверлеи, мобильные медиазапросы) |
| `app.js` | монолитный скрипт интерфейса (поиск, IOC-поповеры, README) |

Актуальная реализация:

- стили — `app/static/css/core.css`, `base.css`, `layout.css`, `components.css`, `about.css`, `utilities.css`;
- скрипты — `app/static/js/*.js` (модули `app`, `theme`, `store`, `search`, `attacks`, `docs`, `palette`, `tray`, `utils`).

Каталог сохранён только для истории и может быть удалён без влияния на работу приложения.
